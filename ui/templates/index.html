ℹ️ Device Detection

If NI DAQ devices are not detected, follow these steps in order:

  1. Refresh — Click Refresh in the toolbar to rescan for connected devices.
  2. Check wiring — Verify that each NI DAQ device is powered on and that USB or Ethernet cables are securely connected.
  3. Configure Chassis IP — If using Ethernet cDAQ, configure the chassis IP in NI MAX and ensure it shows as Connected, then click Refresh.
    Steps to configure in NI MAX:
    1. Open NI MAX from the Start menu
    2. Under Remote Systems, wait for the chassis to appear (may take 10-30 seconds)
    3. If chassis does not appear, click Create New → Remote System and enter the chassis hostname or IP
    4. Right-click the chassis → Properties → Network Settings to set/verify the IP address
    5. Ensure chassis shows as Connected with a green checkmark
    6. Return here and click Refresh to detect the chassis
  4. Restart the server — If devices are still not detected, stop and restart the ATS Test System server, then click Refresh again.
